#  JRConsult

Repositório criado para armazenar e organizar **atividades e exercícios em JavaScript**.  
Cada diretório representa uma atividade prática com código para aprendizado e prática de lógica de programação.

---

## 📁 Estrutura do Repositório

| Pasta | Descrição |
|--------|------------|
| `D1-Calculo-de-IMC` | Calcula o Índice de Massa Corporal (IMC) com base em peso e altura informados pelo usuário. |
| `D2-conceito-notas` | Filtra as notas maiores ou iguais a 7 e converte em conceitos: **BOM** e **EXCELENTE**. |
| `D3-Nomes-em-maiúsculas-e-filtragem-de-idade` | Filtra pessoas com 18 anos ou mais e retorna os nomes em letras maiúsculas. |
| `D4-login-simplificado` | Exercício prático sistema de login simples. |
| `D5-lista-compras` | Sistema interativo usando Arrays, métodos de inserção (push), remoção com filter e busca com startsWith. |
| `D6-tarifas` | Um programa que exibe o valor de uma tarifa dependendo da idade e tipo do usuário. |
| `D7-cafe` | Criação de programa para pedidos de café (com reduce). |
| `D8-notas` | Converter notas usando: filter, map, ternário e Math.round. |

*(Novas atividades serão adicionadas conforme o progresso.)*
